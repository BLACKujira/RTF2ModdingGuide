# 替换背景音乐

在虚幻引擎中，`.pak` 文件被用于打包各种资源。游戏运行时会按照特定的优先级加载这些 `.pak` 文件。如果两个 `.pak` 文件中包含同一路径的资源，后加载的那个会覆盖先加载的。
虚幻引擎为了方便补丁和DLC系统，会自动让文件名带有 `_P` 后缀的 `.pak` 拥有最高优先级。因此，我们只要创建一个与原游戏相同资源路径的替换文件，并打包成 `_P.pak`，就能在不修改原文件的情况下覆盖游戏中的音频。

### 关于 CUE 文件

*R-Type Final 2* 的音乐和音效都通过 `Sound Cue` 资源文件控制。
`Sound Cue` 可以理解为一个“音频逻辑蓝图”，它定义了音频文件如何播放——例如播放顺序、循环、淡入淡出、音量控制等。

游戏的 BGM 对应的 `Sound Cue` 资源保存在 `RTypeFinal2/Content/Sound/Cue` 

我们需要做的，就是创建一个与原版 `Sound Cue` 路径和名称一致的替代版本，并让它播放我们自己的音乐。然后再将其打包成 `_P.pak` 覆盖原游戏资源。

## 第一步：创建项目

1. 启动 *虚幻引擎 4.26.2*
2. 选择 `新项目类型` -> `游戏`，点击 `下一步`。
3. 项目模板设置为空白，点击 `下一步` 。
4. 将项目类型设置为 `蓝图`
5. 设置保存路径，并**将项目名称设置为 `RTypeFinal2`**
6. 点击 `创建项目`，稍作等待

## 第二步：创建Dummy音效类

CUE 文件依赖“音效类”（Sound Class）来控制播放逻辑，比如全局音量、淡入淡出等。
为了让游戏能够正确识别我们的替换 CUE，同时仍使用原版的播放逻辑，我们需要创建一个“空壳”（Dummy）音效类。它的作用只是占位——名称和路径与原版相同即可，实际逻辑仍由游戏的原版类执行。

1. 在虚幻引擎的内容浏览器中右键创建一个文件夹，命名为 `Sound`
2. 在 `Sound` 文件夹中创建子文件夹 `Mix`，此时的游戏目录应当如下
3. 在 `Mix` 文件夹中右键，选择 `音效` -> `类` -> `音效类`
4. 将创建的音效类命名为 `Sound_BGM`

> 这个 Sound_BGM 不会被打包进最终的 PAK，它仅用于在编辑器中让 CUE 找到正确的引用。

## 第三步：剪辑音频文件

1. 使用任意音频编辑软件（或者可以剪辑并导出音频的视频编辑软件）打开要替换的音乐
2. 将音频修建成 “开头段” 和 “循环段” (开头带一段循环也没问题)
3. 通过比对波形等方式精确定位循环开始与结束位置，确保衔接平滑
4. 分别导出开头段和循环段。格式可使用WAV或者OGG（比特率可以高一些）
   
## 第四步：定位需要替换的 Sound Cue

1. 打开 `FModel`，载入游戏的所有 `.pak` 文件
2. 在 `RTypeFinal2/Content/Sound/Cue` 目录中寻找可能是目标文件的 `Sound Cue`
3. 双击 `Sound Cue` 资产文件，在右侧的 JSON 区域找到最下方 `Type` 为 `SoundNodeWavePlayer` 的节点
4. 点击这些节点的 AssetPathName 或 ObjectPath 的路径，FModel 会弹出音频播放器
5. 播放后确认该 `Sound Cue` 是否是需要替换的 BGM

## 第五步：创建CUE

1. 回到虚幻引擎，在 `Sound` 文件夹中再创建一个子文件夹 `Cue`
2. 将前面导出的音频文件导入项目 `内容` 中的任何文件夹（建议放在 Cue 文件夹内）
3. 在 `Cue` 文件夹右键，选择创建 `音效` -> `Sound Cue`，命名为目标 CUE 的相同名称
4. 打开刚刚创建的 `Sound Cue` ，将左侧的 `类` 设置为之前创建的 `Sound_BGM`
5. 在右侧的蓝图中添加一个串联器节点，将串联器的输出连接至“喇叭图标”的输出节点
6. 将导入的两个音频文件拖到蓝图中，会自动创建两个音频节点
7. 将 “开头段” 接到串联器第一个输入，“循环段” 接到第二个输入
8. 选中 “循环段” 的节点，在左侧属性中勾选 `循环`

## 第六步：打包到特定数据块

1. 在菜单栏选择 `编辑` -> `项目设置`
2. 在项目设置的 `打包` 里勾选 `生成文件块`
3. 再在菜单栏选择 `编辑` -> `编辑器偏好设置`
4. 勾选 `实验性功能` -> `用户界面` -> `允许ChuckID指定`
5. 在资产浏览器中选中 **Sound Cue和两个音频文件**
6. 右键 `资产操作` -> `分配到数据块`
7. 将 `数据块ID` 改为非0的数字，确保这三者的数据块ID相同

> 注意：不要把 Sound_BGM 分配到 Sound Cue 的同一个数据块，最好让它待在默认的的 0 号数据块。否则会覆盖原游戏的全局音效类，导致所有 BGM 无法播放。

## 第七步：打包PAK并放入游戏

1. 从菜单栏选择 文件 → 打包项目 → Windows (64-bit)
2. 选择导出路径（我这里选择直接导出到项目文件夹）。稍等片刻，首次生成可能耗费较长时间
3. 在导出目录中打开 `WindowsNoEditor\RTypeFinal2\Content\Paks` 这个文件夹
4. 找到 `pakchunk{你刚刚指定的ID}-WindowsNoEditor.pak` 这个PAK，`Sound Cue` 和音频文件应该都打包到了这里面
5. 将这个文件重命名为 `{随便什么名字}_P.pak` ，注意末尾的 `_P` 是必不可少的
6. 使用 [安装PAKMod](../../Chapter1_TheBasics/zhs/安装PAKMod.md) 的方式将其放到游戏目录中
7. 启动游戏，检查是否成功替换目标 BGM。
